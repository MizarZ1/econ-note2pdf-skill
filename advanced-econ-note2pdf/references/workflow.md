# 宿主执行流程

## 开始与配置

开始转换时按 SKILL.md 合并询问尚缺的用途、整理权限和原文强调方式；使用者已明确的信息直接沿用。把结果写入 project.json 的 mode 与 presentation，恢复任务先读取已保存选择，不重复询问。配置属于每次转换任务，由执行 agent 向该任务的使用者提出，不能把开发者在测试中的样式选择固化为所有课程的偏好。

等待回复期间可准备图片、查看布局和记录内容块。可选样式未答时，在合理等待后说明使用 plain；purpose 未明确且无法推断时使用 revision。整理权限不明则先做忠实转录基础，避免擅自补写。后续改用途或样式要更新配置并重新组装、编译和检查页面。

## 材料与上下文

先查看每张全图，记录版面、课题、已写内容、覆盖区域和可能的顺序。再读局部高清图，不能用低分辨率预览作为密集公式的唯一证据。PDF 自带文本只用于定位，不代替查看手写内容。

显式输入顺序优先；目录自然排序只是候选。结合时间下标、标题、推导接续和擦写痕迹判断；有两个都合理且影响推导的顺序时询问用户。其余可独立整理的部分继续处理。

相邻照片共同覆盖同一板面时，按内容区域比较：完全重复可合并；新条件、修正的符号、后续箭头、被擦掉的中间步骤单独保存。不要仅用图片相似度或相同公式第一行决定去重。

## 建立单元

单元是一个可独立理解的问题、命题或推导，不等于一页照片。连续推导可跨多页；一张板书也可拆成多个单元。登记每个来源的文字、公式、图、表和有意义边注；正文纳入、确认重复、明确排除、无法识别均在 coverage 中体现。

先核对忠实转录基础和符号含义，再建立复习版。保存上下文简记：当前目标、已用条件、待接续等式、变量含义、图中对象、尚未结束的证明。少量符号可在正文首次出现处解释，不必为它们生成独立记号表。不要让一个 LaTeX 环境跨文件悬空；用完整 align 环境和公式引用保持连续。

开始写 study 正文前，列出各单元的知识依赖与阅读顺序。合并重复说明，把新符号、前置条件和结论放在读者需要的位置。用于复习时展开关键推理与应用条件；用于查阅时提供紧凑而完整的主题组织。输出的段落应直接讲授这些内容，不按“第一张照片、第二张照片”介绍材料。

符号表按作用域区分 `β`（贴现因子/回归系数）、`λ`（乘子/特征值）、`k`（资本/索引）、`E`（期望/集合）。沿用教师记号，必要的规范化在全节一致应用并记录。

## 识别与整理的交替

看不清的式子先定位原图区域，放大或轻度增强，再结合已确认的定义和上下文核查。经济学知识只帮助提出候选，不能让候选变成已确认内容。对改变均衡、检验结论、符号方向的歧义使用 critical。

模型补充内容放进 explanation 块；更正放进 correction 块并记录依据。用户确认的手写习惯可写进当前课程符号/事项记录；不要把某位教师的写法变成所有课程的规则。

source 与 explanation 的保存边界不要求它们在正文分成两大部分。按推理链交错组织，原式后紧接解释、解释后引出下一步。启用强调色或色块前核对每块身份，避免把衔接说明、补充条件和更正一并标成原文。

## 编译修复

修复只改源内容与模板，随后重新组装。读取错误位置及其前后块，连同原图判断；先排查环境闭合、非法字符、宏缺失、图表尺寸，再处理复杂图形代码。每次确认没有减少原有条件、公式行数或图表信息。

同一故障最多 3 次有依据修复。仍失败时保存内容，使用逐单元诊断隔离失败单元；出现公共模板问题则修公共模板，不能把所有章节都排除。部分 PDF 保留缺失位置提示，技术错误留在日志。

## 两次复核

内容复核：原图逐区域对照覆盖清单，逐项检查上下标、量词、条件、符号、等式/近似、图表标签和边注。再脱离原图通读正文：读者是否知道问题与条件、新符号是否已解释、每一步为何承接上一步、结论可在何时使用。检查跨节引用与推导依赖，以及 source 强调范围是否混入补充。完成后登记 unit 的 content review。

页面复核：查看最新 PDF 的所有渲染页，关注长公式、矩阵、相图和回归表；检查中文显示、标题与正文分页、公式截断、图形标签拥挤、表注丢失、未解析引用、字号过小和图文错位。原文色块要检查跨页与图表完整性，少量记号不得制造无意义的空白页。宿主预览异常时区分文件本身与宿主重编译/显示问题，按宿主说明处理。完成后登记该 mode 的 layout review。

这两种复核由宿主执行，不是脚本自动证明。内容或 PDF 改变后旧复核失效。
