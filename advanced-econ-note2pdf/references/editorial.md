# 讲义编辑规则

## 模式与权限

- faithful 保留原始信息、步骤顺序和重要删改痕迹；可排版、规范明显字形，不擅自修正学术结论。疑似错误保留，必要说明进附录。
- study 组织成可独立阅读的讲义。purpose 为 revision 时解释问题、条件、关键推理与应用；reference 时用主题标题紧凑组织定义、条件、公式、适用范围和引用。两者都保留推导依赖，不能拆散条件与结论，也不强制统一栏目。
- both 共用核对后的忠实基础及来源，再派生 study；解释只进 study，更正不能污染 faithful 原式。配置字段与块约束见 [内容契约](content-model.md)。

## 内容与衔接

正文直接讲述概念、问题和推理，例如“由状态方程与边界条件得到……”，不逐条转述照片。先确定本节对象、已知条件、目标及后续依赖；通过代入、求导、约束、取极限或比较静态等实际关系衔接，不能用空泛过渡掩盖缺步。新符号先解释再使用，跨图箭头还原为推导关系，不按图片边界分页。

按理解顺序交错放置 source 与 explanation：关键原式后紧接含义、变形依据或适用条件，再引出下一步；避免原式与讲解分成两大部分，不加入无关教材综述。来源定位留工程或附录，正文只在理解冲突／缺失需要时提及来源。

用户要求中英对照时，保留英文原文并紧邻中文解释，不能仅留下英文术语。

保留约束、初始／终端条件、存在性／唯一性条件、证明步骤、图表注释和单位，包括角落边注。study 可补省略的代数步骤，以“补充推导”或统一整理说明区分；实质新增假设须在使用位置明确。只有结论的材料不能伪称已有证明。题设不全时先查相邻材料，仍缺则以明确适用条件的解释衔接，不能把熟悉模型当原题事实。

有依据的更正存 correction：faithful 保留原式，study 给修正式，事项记录依据；未验证猜测不作更正。用户确认只记录实际确认内容，不推测时间或身份。一般来源边界用一次图例或整理说明交代，不逐段免责。

## 疑点与附录

note 用于不影响结论的一般疑点，附录按章节／块定位具体对象和背景。critical 用于改变结论、符号方向或适用条件的歧义及关键缺失（如 Euler 时间下标、图中稳定方向）；正文相邻位置简短提示，附录给细节，不能隐藏到末尾。

可辨认内容转为 LaTeX，能可靠还原的图重绘。确实无法还原时，只裁切最小必要区域，以关联事项写明原因并在附录展示；正文保留已确认内容。截图登记与 gap 规则见契约，图表语义见 [图表规则](figures-and-tables.md)。

有阅读价值的 resolved 更正可留附录；无价值的已解决事项可隐藏，未解决缺失不能借 appendix:false 隐藏。工具故障、重试、环境安装和日志不进入学术附录。

正文不展示流水线状态、识别置信度或技术报错。

## 阅读排版与原文样式

标题通常到 subsection；字号、字重、强调色和间距保持一致，标题直接说明主题且紧邻正文。短材料保持紧凑，避免封面式留白、同义标题堆叠或为少量符号单开一页。正文用自然段、对齐公式与定理环境，长推导可分行分页并解释关键转换，结论须易于联系其条件。

少量符号在首次出现处解释；确有查阅价值再建紧凑记号表，长表分章节，避免重复定义。只给需要引用的公式编号，检查图题、表题及交叉引用。

source_style 沿用任务配置：plain 统一排版；accent 用深蓝；box 用浅底细边或侧色条，框中文字与公式保持深色、正常字号和足够对比。强调只作用于已核对的 source，explanation 与 correction 保持普通正文样式并紧随相应原文。含补充条件或推导的混合段落拆成不同 origin 的连续块，不能整段标为原文。

用色时开头只给一次简短图例，仍完整保存来源。色框留适度内边距、统一段间距并自然跨页，实看分页后的文字、公式及边框；含 figure／table 浮动环境或 longtable 的块由工具改用强调色以保留分页。图形用线型／标签辅助颜色表达，不能靠整页图片或极小字号换取完整。
