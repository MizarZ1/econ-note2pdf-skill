# 讲义编辑规则

## 模式

faithful 保持原始信息、步骤顺序与重要删改痕迹；可做排版和明显的字形规范化，不擅自修正学术结论。疑似错误保留，必要说明进入附录。

study 把已识别内容组织成可独立阅读的讲义。presentation.purpose 为 revision 时，围绕“要解决什么问题、条件是什么、怎样推出结论、如何应用”组织，解释关键转换与易混条件；为 reference 时，采用便于定位的主题标题，紧凑列出定义、成立条件、公式、适用范围与相互引用。两种用途都保留推导依赖，不能为方便检索拆散条件与结论，也不强制每节使用相同栏目。

both 共享一套来源记录；先建立可靠忠实内容，再派生 study，避免两次独立识别得出不一致结果。解释块只进入 study，忠实版不能误用更正后的式子。

## 完整性与逻辑

以学科内容为叙述主体。直接写“定义 Hamilton 函数……”“由状态方程与边界条件得到……”，不逐条转述“板书写道”“照片右侧给出”。来源定位留在记录或附录，只有读者理解原文冲突或缺失时才在正文提及来源。

先建立章节之间的依赖：本节研究对象、已知条件、要得到的结果和下一节会使用的结论。段落之间通过实际数学关系衔接，例如代入、求导、约束、最优化、取极限或比较静态；不用空泛的过渡句掩盖缺失步骤。新符号先解释再使用，定义、假设、推导、结论各自承担清楚的作用。

按理解过程交错放置 source 与 explanation 块。一个关键公式之后就解释其含义、变形依据或适用条件，再引出下一个公式；不要把所有原式堆在前面、把所有解释集中到末尾。补充解释应回答当前读者的问题，不添加与本节推理无关的教材综述。

保留约束、初始/终端条件、存在性/唯一性条件、证明步骤、图表注释和单位。即使它们只写在板书角落，也可能决定公式成立范围。把跨图箭头还原为推导关系，不能简单按图片边界分页。

教师省略的代数中间步可以在 study 中补出，标为“补充推导”或在统一整理说明中交代；数学论证所需的新假设必须在使用位置明确。材料只有结论时，不伪造“老师证明了……”的叙述。

当原材料只展示局部条件时，先核查相邻材料能否补全问题。仍缺题设时，可以用明确标注适用条件的解释把局部内容连接起来，不能把熟悉的模型设定当作原题事实。一般来源边界用一次图例或整理说明交代，不逐段添加“这不是原文”的防御性句子。

改正原文结论须保存 faithful 原式，study 给出修正式和依据记录；尚未验证的猜测不当作更正。用户直接确认的修正记录其确认内容，不推测确认时间或身份。

## 提示与附录

一般疑点写 note：例如边注缩写不清但不影响结论。附录按章节/内容块定位，描述具体不确定对象和必要背景，避免通篇“可能有误，请自行核实”。

严重事项写 critical：例如预算约束中负号不清、时间下标决定 Euler 方程、关键假设缺失、图中稳定方向无法辨认。正文在相邻位置一句提示，能保留原图片段时一起保留；不要让读者在附录末尾才发现结论基础不确定。

 resolved 更正可留附录；没有阅读价值的已解决事项不展示。工具失败、重试、环境安装和日志不进入学术附录。缺失内容不能靠设置 appendix:false 隐藏。

## 阅读排版

标题层级通常到 subsection 即可；总标题、章节标题与小标题通过一致的字号、字重、强调色和间距建立清楚层次，标题文字直接说明主题。留白用于区分知识单元，标题应与后续正文保持相邻，避免孤悬页末。短资料保持紧凑，避免封面式大留白、同义标题层层重复或为少量符号单开一页。正文使用自然段、对齐公式和合适的定理环境；步骤较长时分行并解释关键转换。

少量符号在首次出现处自然解释；确实有查阅价值时再用紧凑记号表，长表按章节整理。避免重复定义同一符号。只给需要引用的公式编号，保证图题、表题和正文交叉引用可用。长推导允许合理分页，结论不要与所属条件分到难以联系的位置。

presentation.source_style 按任务开始时使用者的选择设置，不把某次样例偏好变成所有任务的默认。plain 时统一排版；accent 用深蓝强调已核对的原文/原式；box 用浅彩色框呈现这些内容，优先浅底色配细边或左侧色条，框中文字和公式保持深色、足够对比与正常字号。色框只容纳原文/原式，讲解保持普通正文样式，紧随对应内容自然衔接。样式根据块的 origin 决定，不能把含有新增假设或补充推导的整段标为 source。correction 在 study 中属于更正内容，不冒充原文。混合内容应拆为连续的 source、explanation 或 correction 块，再按阅读顺序组合。

采用颜色或色块时，在开头用一次简短图例说明含义，来源记录仍完整保存。框内留出适度边距，框与讲解之间保持统一间距，避免密集边框割裂推理。色块应允许长内容自然跨页，不能导致长公式截断、图表丢失或整页空白；实际检查分页后的文字、公式及边框是否完整。含浮动图表或 longtable 的来源块由工具改用强调色，保留原有分页行为。图形保留线型/标签双重区分，颜色对比清楚，不能只靠颜色表达经济含义。不能靠把整页压缩成图片或极小字号获得“完整”。
