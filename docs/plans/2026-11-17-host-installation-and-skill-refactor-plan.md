## 目标与边界

1. 补齐 Claude Code、Claude 网页／桌面端 Skills 上传，以及 DeepSeek Harness 的安装与加载说明；各入口使用同一份核心 skill 和完整 ZIP。
2. 合并重复配置、编辑和复核说明，按阶段读取参考。优先保证内容与阅读质量，不预设删减比例或 token 降幅。

本轮不改变脚本、模板、数据字段与三种整理模式。模型理解继续由宿主完成，不增加模型 API 或多 agent 运行依赖。

## 保留的质量要求

- 保留原件及来源；公式、条件、推导、图表和有意义边注均属于内容。
- 沿用用户已明确的用途、权限、语言与样式，不擅自扩大整理权限。
- 原文、解释与更正分开记录；不补造模糊内容，新增实质假设就地说明。
- 正文连贯、可独立阅读；关键歧义局部提示，一般疑点进附录。
- 可辨认内容转录或可靠重绘；无法还原的最小截图只作为有原因、有来源的附录证据。
- 内容对照与全部最终页面查看分别执行，编译成功不能代替复核。
- 恢复时遵循当前状态，区分部分完成、未复核与已复核。
